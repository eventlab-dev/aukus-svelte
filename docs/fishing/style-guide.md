# Стиль UI

Пиксельный интерфейс поверх воды: 1 px линии, индиго и periwinkle, всё в виртуальных единицах
480×270. У каждого правила указан источник в `src/lib/minigames/fishing/engine/`. Если код и документ расходятся,
верен код; расхождения перечислены в «Разрешённых отклонениях».

## Границы и обводки

- `drawPanelFrame()` (`ui/theme.ts`) — рамка окна: внешний `rect` 1 px `UI.ink` (0x141a3d),
  внутренний `rect(x+1, y+1, w-2, h-2)` 1 px `UI.periwinkle` (0x8299e6, alpha 0.55).
- `drawPanel()` — заливка `UI.panel` (alpha 0.95) + `drawPanelFrame` + фаска 2 px: верх
  `UI.periwinklePale` 0.45, лево 0.2, низ `UI.ink` 0.55, право `UI.ink` 0.25. Опции:
  `shadow: true` (сдвиг 3 px), `inner: false` (без фаски).
- Окна без скруглений (`radius` по умолчанию 0). Скругление 2 px — только у `makeKeycap()`.
- Поверхность внутри панели обводится одним `stroke` 1 px, а не вторым `drawPanelFrame`
  (`ui/AreaShortcuts.ts`: значок погоды — плитка `UI.ink` 0.85 и обводка `UI.panel` 0.9).
- Одна линия на стыке, не две. Сетка 4×4 (`CodexGrid.paintGridLines()`) рисует рёбра один раз;
  кнопки ячеек — `bare: true` (`ui/Button.ts`), без заливки и рамки. В сегментном баре
  `CodexTabs` пропускает hairline у выбранного сегмента.
- Разделитель внутри окна — 1 px `UI.periwinkle` с alpha 0.3 (футер карточки записи,
  `ui/codex/setup.ts`) или 0.4 (разделитель внутри карточки, помощь).
- Значки контролов: крестик и фулскрин — готовые тайлы 16×16 из набора Kenney
  (`art/tile_0016.png` и `art/tile_0023.png`), перекрашенные в палитру (`UI.ink`, `UI.primary`,
  `UI.periwinklePale`); пауза (`drawPauseIcon`, `ui/theme.ts`) и книга (`drawCodexMark`,
  `ui/codexMark.ts`) рисуются кодом, но в той же обводке: чернильная плита 2 px со светлым
  глифом внутри. У паузы две полосы 6×12 с ядром 2×8, у книги плита 12×12, обложка
  `UI.periwinklePale`, страницы `UI.primary` и закладка. Значок встаёт в квадрат 16×16 по
  центру кнопки (`Button.icon` и `Button.iconTexture`).
- Кнопка со значком — один размер на всю игру: `ICON_CONTROL` (`ui/metrics.ts`) плюс рост
  `target()` до 44 CSS px на тач. Этот же размер берут кнопки закрытия окон (кодекс, помощь),
  иначе на мелком телефоне значок крестика оставался на шаге 1×, пока значки HUD уходили на
  2×, и крестик был вдвое меньше остальных.

## Отступы попапа

- `SCREEN_INSET = 12` (`ui/theme.ts`): окно на весь кадр `x: 12, y: 12, width: 456,
height: 246` (кодекс). Помощь — попап 380×186 по центру кадра.
- `PANEL_PAD = 16` — от рамки до содержимого со всех сторон: `CONTENT.left = 28`,
  `CONTENT.right = 452`, `CONTENT.width = 424`.
- Заголовок + закрытие: `TITLE = { x: 28, y: 28 }`. Кнопка закрытия — `Button` 18×18 на
  десктопе и `ICON_CONTROL` на тач (`ui.pick`), `variant: "secondary"`,
  `iconTexture: game.assets.close`, встаёт в `x = 434`. Заголовок
  `anchorInk(title, "left", "center")` на `TITLE.y + 9`, то есть на середину кнопки.
- Тело начинается на `BODY_TOP = 78`; табы `{ x: 28, y: 54, width: 248, height: 16 }` —
  та же полоса, что и в помощи.
- Колонки идут до нижнего инсета `242`: у кодекса нет общей футерной полосы. Свой футер
  (`FOOTER = 20`, hairline на `height - 20`) есть только у карточки записи.
- Зазор между колонками `GUTTER = 10`; ростер — `ROSTER_SHARE = 0.6` от `424 - 10`.
- Диалог паузы: `PANEL = { x: 130, y: 53, width: 220, height: 137 }`, кнопки 188×21, зазор 6,
  три строки (продолжить, звук, в меню).

## Типографика

- Лестница размеров — 7 / 8 / 10 / 11 / 14 / 16 / 18 (`makeText({ size })`):
  - 18 — слово в заголовке окна (кодекс, пауза);
  - 16 — заголовок кодекса;
  - 14 — заголовок попапа помощи;
  - 11 — подпись кнопки и название водоёма;
  - 10 — имя в карточке записи и кнопки меню;
  - 8 — табы, подписи, прогресс;
  - 7 — строки помощи, подсказка заброса.
  - Крупнее — только намеренно: 26 (название игры), 22 (заголовок boot), 14/12 (кнопки меню).
  - Мельче 7 — только плотные числа и радиометры (6.5, 6, 5.5, 4.8, 4.5). Ниже 4.5 не опускаться.
- Подписи — заглавными в `texts.ts`. Строчные — только внутри предложений (описания рыб,
  строки помощи).
- `letterSpacing` растёт с размером: 0.2 — плотные подписи, 0.3–0.6 — обычные подписи,
  0.8–1 — заголовок окна 16, 2 — «ПАУЗА» 18.
- Насыщенность: 800 — заголовки, 700 — табы и служебные подписи, 600 — кнопки, 500 — умолчание.
- Цвет: `UI.text` на тёмном, `UI.textMuted` для второго плана, `UI.textOnBright` — только на
  светлой заливке. Белым по `UI.periwinkle` не писать (контраст 2.5:1).
- `makeText` ставит якорь только по X; по вертикали — `anchorInk(text, align, "top" | "center")`
  или `inkTopInset(text)`. Ширину для раскладки брать `inkWidth()`, а не `text.width`.
  `trim: false`, `resolution = 4`, `roundPixels = true`.
- Обводка — одна на весь интерфейс: `TEXT_OUTLINE = 2` (`ui/theme.ts`), включается опцией
  `makeText({ outline: true })`. Её не ставят вручную после создания текста: `inkWidth`,
  `inkAnchorX` и `inkBox` читают ширину обводки из стиля, и добавленная позже она сдвигала
  якорь на пол-обводки, а базовую линию — на пиксель вниз. Обводят только текст, стоящий прямо
  на сцене без панели, — заголовок меню и boot (26/22), подсказку заброса (7) и всплывающие
  ярлыки (10–14). Ширина 2, а не 2.5 или 3: canvas обводит путь по центру, поэтому 2 даёт ровно
  1 px чернил наружу и целый пиксель на внешнем крае, как у всех рамок интерфейса; 2.5 на
  седьмом кегле съедал внутренние 1.25 px и превращал подсказку в мягкое пятно.

## Цвета и состояния

Роли из `ui/palette.ts` — брать только их:

| Роль                             | Hex                            | Где                                     |
| -------------------------------- | ------------------------------ | --------------------------------------- |
| `ink` / `scrim`                  | 0x141a3d / 0x1a2148            | обводки, тени, линии сетки / затемнение |
| `panel` / `panelAlt` / `surface` | 0x3f4b91 / 0x4b59a4 / 0x5d6dbb | окно / чипы / ховер                     |
| `periwinkle` / `periwinklePale`  | 0x8299e6 / 0xc9d4f8            | контролы, hairline / блик               |
| `primary`                        | 0xeef3ff                       | главная кнопка, выбранный таб, фокус    |
| `text` / `textMuted`             | 0xeef2ff / 0xc2cdf0            | основной / второй план                  |
| `textOnBright`                   | 0x1c2554                       | текст на светлой заливке                |

- Варианты `Button`: `primary`, `secondary` (`UI.periwinkle`), `ghost` (без заливки до наведения),
  `card` (`UI.panelAlt`, ховер `UI.surface`), `danger` (`UI.danger`, белая подпись).
  Ховер — `fillActive`; нажатие — `fillPressed` и подпись на 1 px вниз.
- Ховер не двигает текст: марки `>` и `<` — отдельные `Text`, слово стоит на месте.
- Выбранное состояние: ice-white заливка, тёмная подпись, верхняя линия `UI.periwinkleLight`.
- Фокус — два кольца (`Button.redraw`): `rect(-3, -3, w+6, h+6)` 1 px `UI.ink` 0.7 и
  `rect(-2, -2, w+4, h+4)` 1 px `UI.primary`.
- Выключено: `alpha = 0.5`, подпись 0.6, `eventMode = "none"` (`Button.setEnabled`).
  Затемнение: `Scrim` 0.72 под окнами, 0.42 под полосой погоды в бою.

## Раскладка

- `VIEW = { width: 480, height: 270 }` (`config.ts`) — единственные единицы; CSS-пикселей
  и процентов в UI нет.
- Дробные значения округляются: `Math.round` в рёбрах сетки, `edge()` в `CodexTabs`,
  `SelectionRing.aim()`, `placeRailCard()`.
- Окно 456×246 в (12, 12); диалог 220×137 в (130, 53); кнопки меню 220×28 при x = 130.
- Сетка кодекса: 4×4, 16 слотов, `cellWidth = 62`, `cellHeight = 41`.
- HUD: справочник 20×20 в (424, 12) и пауза 20×20 в (448, 12), зазор 4 (`ICON_CONTROL` —
  квадрат 16 px под значок плюс воздух по краям); карточки-переходы
  68×40 в (8, 222) и (404, 222) при
  `MARGIN = 8`; полоса погоды 178×20 в (151, 242); шкала силы 60×7 на `angler.y - 35`.
  Внутри полосы: карточка 42×16, зазор 2, padding 2, иконка 12, зазор до подписи 3,
  четыре карточки — по одной на фронт (`weatherRailLayout.ts`).

## Анимация

- Попап приходит снизу на 22 px за `FLY_TIME = 0.28` с, уходит за кадр при закрытии
  (`ScreenManager`, `easeOutCubic`), альфа `min(1, eased * 1.4)`. Скрим не двигается.
- Пауза: `FLY_IN = 22`, `FLY_TIME = 0.24`, `FLY_OUT_TIME = 0.2` (`ui/PauseMenu.ts`).
- Кодекс: `CODEX_FLY_LIFT = 26`, `CODEX_FLY_TIME = 0.34` (`ui/CodexOverlay.ts`).
- Карточки-переходы: `SLIDE = 26`, `SLIDE_TIME = 0.3`; полоса погоды: прокрутка 0.34,
  перестройка — фейд 0.2.
- Ховер-обводка кодекса ставится сразу на слот, без переезда (`SelectionRing.aim()`).
- Смена экрана без попапа: фейд 0.13 наружу и 0.17 внутрь (`ScreenManager`).

## Чек-лист новой панели или попапа

1. Окно: `SCREEN_INSET = 12`, `drawPanel(panel, 12, 12, 456, 246, { fill: UI.panel,
alpha: 0.97, shadow: true })`; содержимое от `PANEL_PAD = 16`.
2. Заголовок 16–18, `anchorInk(title, "left", "center")` на середину кнопки закрытия;
   кнопка закрытия — 18×18 на десктопе и `ICON_CONTROL` на тач, `iconTexture: game.assets.close`.
3. Тело с 78, табы с 54 высотой 16, зазор между колонками 10.
4. Свой футер — только у карточки записи: полоса 20 px, hairline на `height - 20`,
   строка по центру полосы; нижний отступ окна — 16.
5. Одна линия на ребро; сетка — одним слоем линий, ячейки — `bare`-кнопки.
6. Текст — только `makeText` из лестницы размеров, подпись капсом в `texts.ts`, цвет по роли.
7. Кнопки — только `Button`; одна `primary` на окно; `textOnBright` на светлой заливке.
8. Анимация — 22 px и 0.24–0.28 с `easeOutCubic`; координаты целые; проверить в 1× и 3×.
9. Правка UI — `npm run check`; тронули бой — проверить в игре руками.

## Разрешённые отклонения

Эти расхождения между кодом и правилами выше признаны допустимыми; новые код и правки должны
соответствовать правилам, а не этим исключениям.

- Диалог паузы стоит в `y: 53`, выше центра кадра (`ui/PauseMenu.ts`).
- Заголовок паузы ставится по `PANEL.y + 16` с литеральной координатой X (`ui/PauseMenu.ts`).
- Заголовки окон: 18/2 у паузы, 18/1 у кодекса, 14/1 у помощи.
- Пауза на `SCREEN_INSET = 12`, карточки и полоса на `MARGIN = 8` (`ui/GameHud.ts`,
  `ui/AreaShortcuts.ts`).
- Заливка окна 0.92 / 0.94 / 0.97 / 0.98 у разных экранов.
- Hairline 0.2 / 0.3 / 0.35 / 0.4 в разных местах.
- Высоты кнопок 20 / 21 / 22 / 24 / 28 при подписях 8–11.
- Мелкие размеры 6.5 в кодексе, 5.5 в подписи карточки-перехода и 5.5 / 4.8 / 4.5 в полосе
  погоды — только для радиометров и самой плотной подписи.
- Подпись неба в полосе погоды идёт без трекинга (`letterSpacing: 0`): «СНЕГОПАД» — восемь
  заглавных в карточке 42 px, и 0.2 px на букву выносили последний глиф за край.
- «ИГРАТЬ» в меню — 34 px (главное действие), остальные кнопки меню 24 px.
- `makeKeycap` и `keycapWidth` (`ui/theme.ts`) пока не используются ни одним экраном.
